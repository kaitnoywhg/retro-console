# Курсовой проект: Игровая ретро-консоль (Wolf & Eggs)

Проект представляет собой автономное игровое устройство на базе микроконтроллера Arduino. 
Игровой процесс: волк передвигается по трем этажам и ловит падающие яйца. С каждым уровнем сложность возрастает, а лучшие результаты сохраняются в памяти устройства.

## 🛠 Текущий статус проекта
На данный момент реализован базовый игровой процесс (MVP):
- [x] Инициализация OLED-экрана (по шине I2C).
- [x] Стартовый экран с ожиданием нажатия любой кнопки.
- [x] Передвижение волка по 3 этажам (управление крестовиной из 4 кнопок).
- [x] Спавн и падение яиц в случайных координатах по оси X.
- [x] Обработка коллизий (поимка яйца) и звуковое сопровождение (буззер).
- [x] Ограничение дребезга кнопок (использование millis()).

## 📚 Используемые библиотеки (и зачем они нужны)
В проекте используются четыре основные библиотеки:
1. **`<Wire.h>`** — стандартная библиотека Arduino для работы с шиной **I2C**. Она отвечает за передачу данных по двум проводам (SDA и SCL) между микроконтроллером и OLED-экраном.
2. **`<Adafruit_GFX.h>`** — графическая библиотека («художник»). Она содержит базовые команды для рисования примитивов: линий (`drawLine`), прямоугольников (`fillRect`), кругов (`fillCircle`) и вывода текста.
3. **`<Adafruit_SSD1306.h>`** — драйвер для конкретного чипа SSD1306, который стоит в нашем OLED-экране. Он переводит команды от «художника» (GFX) в понятные экрану электрические сигналы.
4. **`<EEPROM.h>`** — библиотека для работы с энергонезависимой памятью микроконтроллера. Позволит сохранять рекорды (High Score) даже после выключения питания.

## 🔘 Принцип работы кнопок (INPUT_PULLUP)
В коде используется режим `pinMode(PIN, INPUT_PULLUP)`. Это означает, что внутри самого микроконтроллера включается встроенный резистор, который «подтягивает» пин к питанию (5В).
- **Кнопка не нажата:** цепь разорвана, на пине 5В. Программа читает `HIGH` (1).
- **Кнопка нажата:** пин замыкается на землю (GND). Напряжение падает до 0В. Программа читает `LOW` (0).
Это позволяет обойтись **без внешних физических резисторов**, подключая кнопку напрямую между пином и землей.

## 📌 Аппаратная часть (Hardware)
- **Микроконтроллер:** Arduino Nano
- **Дисплей:** OLED 128x64 (I2C)
- **Управление:** 4 тактовые кнопки (Вверх, Вниз, Влево, Вправо)
- **Звук:** Пассивный буззер
- **Питание (в планах):** Аккумулятор 18650 + плата зарядки TP4056 + повышающий преобразователь MT3608

### 🔌 Распиновка (Pinout)
| Компонент | Пин Arduino | Примечание |
| :--- | :--- | :--- |
| Кнопка "Вверх" | D2 | `INPUT_PULLUP` (замыкание на GND) |
| Кнопка "Вниз" | D3 | `INPUT_PULLUP` |
| Кнопка "Влево" | D4 | `INPUT_PULLUP` |
| Кнопка "Вправо" | D5 | `INPUT_PULLUP` |
| Буззер | D8 | `OUTPUT` |
| Экран SDA | A4 | Шина I2C |
| Экран SCL | A5 | Шина I2C |

## 🚀 Как запустить (Инструкция для команды)
1. Установите Arduino IDE (версия 1.8+ или 2.0+).
2. Установите библиотеки через менеджер библиотек:
   - `Adafruit GFX Library`
   - `Adafruit SSD1306`
3. Скачайте файл `kurs.ino` из этого репозитория.
4. Подключите Arduino к ПК, выберите плату Arduino Nano и загрузите прошивку.
5. **Важно:** для старта игры после включения/перезагрузки нужно нажать любую из 4 кнопок.
